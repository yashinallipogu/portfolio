# Portfolio design skills

Reference: https://www.jasonindata.com/projects (reviewed October 14, 2026).

The current reference uses a signature masthead, oversized title panel, dark background, thin card borders, and large illustrations beside concise project descriptions. This adaptation preserves Yashi's identity and existing sample content.

| Skill or discipline | Purpose | Available in this session |
| --- | --- | --- |
| Sites | Portfolio structure, responsive HTML/CSS, accessible interactions, implementation and preview | Yes; applied |
| Visual research | Inspect reference typography, composition, spacing, artwork and interaction patterns | Performed through web and browser tools; no separate research skill installed |
| UI / UX design | Establish reading order, navigation, readable mobile cards and keyboard focus | Performed as part of Sites; no separate UI/UX skill installed |
| Computer Use | Inspect the reference and verify the live portfolio in a browser | Yes; applied |
| Imagegen | Generate original project illustrations when real project briefs are available | Available; unnecessary for the existing CSS illustrations |
| Skill Creator | Package a repeated research/design/implementation workflow as a reusable skill | Available; optional, not needed for this edit |

Dark mode is the initial theme. The visitor can switch to light mode, and their choice persists locally. Theme setup runs before page rendering to avoid a flash of the wrong theme. Storage failures do not prevent other page interactions.

The six projects remain sample content. Project destinations, social profiles and the example contact email still require the owner's real details.
